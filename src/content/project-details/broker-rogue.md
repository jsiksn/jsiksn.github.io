## 요약

매매를 '카드 한 번 탭'으로 추상화한 모바일·웹 게임 프로토타입. 복잡한 인터랙션을 UX 관점에서 단순화하는 실험.

- 형태: 개인 프로젝트 · 모바일/웹 게임 프로토타입
- 역할: 단독 기획·설계·배포 (구현은 Claude Code 페어 프로그래밍)
- 배포: 단일 코드베이스 모바일·웹 동시 운영 · GitHub Pages 자동 배포

## 설계와 결정

- **매매 단계 단순화** — 일반 주식앱의 4~5단계 매매 흐름(검색 > 호가 > 수량 > 확인)을 카드 두 번 탭으로 압축했다. "전량 매수 / 50% 매수" 비율 카드를 미리 만들어 수량 입력 단계 자체를 제거했다.
- **내부자 카드 재설계** — "다음 턴 가격 방향을 미리 알려주는" 정보 카드에서 "예측대로 시장이 움직이는" 카드로 재설계했다. 사용자를 단순 예측 검증자가 아닌 "시장을 움직이는 주체"로 전환한다. NEXT DAY 버튼 옆 ▲/▼로 결과를 안내한다.
- **재시도 동기 설계** — 게임 종료 화면을 "파산 / 목표 미달 / 목표 달성" 3종으로 분리하고 "이번 세션 최고 자산"을 함께 표시해, 푸시·랭킹 없이도 재시도 동기를 부여한다.

## 성과

단일 코드베이스로 모바일·웹 동시 운영, GitHub Pages 자동 배포 파이프라인 구축. 카드 9종, 모드 2종(개미 10일 / 세력 20일), 96틱 실시간 차트 완성.
