## 요약

Hacker News의 조기 트렌드를 자동 감지해 한국어 블로그 글로 가공·발행하는 28노드 자동화 파이프라인.

- 형태: 개인 프로젝트 · 자동화 워크플로우
- 역할: 단독 설계·운영 (노드 로직 직접, 노드 내 코드·프롬프트는 AI 영역)
- 규모: 28노드 파이프라인 · 약 60건 자동 발행 누적

## 설계와 결정

- **자체 트렌드 감지 지표 설계** — "가속도 = 점수 ÷ 경과 시간" 공식을 직접 정의했다. 3개 조건 동시 필터(24시간 이내 / 점수 100 / 가속도 15/hr)로 "빠르게 오르는 글"만 추출한다.
- **다중 AI·외부 API 통합** — LLM(OpenRouter — 키워드 추출/한국어 가공) + 검색(SerpApi Google News) + 이미지 생성(ComfyUI) + 블로그 자동 발행(Tistory) + Gmail 알림. 각 단계에 적합한 도구를 선택해 연결했다.
- **다국어 콘텐츠 가공** — 영문 HN 본문 + 댓글 + 관련 뉴스 3개 소스를 통합해 한국어 블로그 글로 LLM 가공한다.
- **비동기 작업 처리** — ComfyUI 이미지 생성의 비동기 특성에 맞춰 "Has Image? → Wait → 재확인" 폴링 루프를 설계했다.
- **운영 안정화** — 초기 실행 단계에서 빈번하던 LLM 부하 기반 오류를, 웹 크롤링과 LLM 가공 단계를 분리하는 구조 개선으로 해결했다.

## 성과

약 4개월 가동, 약 60건 자동 발행 누적. 감지부터 발행까지 전 워크플로우를 무인 운영했다.

## 기술

n8n · OpenRouter(LLM) · SerpApi(Google News) · ComfyUI(이미지 생성) · Tistory API · Gmail
