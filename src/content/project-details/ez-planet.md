## 작업 화면

개발자용 포트폴리오 PDF에 실린 EZ PLANET for AIOps 작업물입니다. 역할은 UI·UX 기획, 디자인, 퍼블리싱.

- 프로토타입 14장 — Content Group 목록·생성, 레코드 목록, Scheduler, Collector, Labeling(데이터셋·정책·편집 화면), Experiment 목록·상세, 레코드 가져오기, 관리자 정보 입력, Report 관리·Template, 화면 흐름
- Storybook 1장 — 공통 컴포넌트
- 정책 문서 2장 — 입력 검증 명세, Content Management UI 정책
- 디자인 시스템 3장 — Icon, Button, Form
